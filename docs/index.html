02

生成AIのきほん

生成AI(ChatGPT・Geminiなど)は、文章で頼むと文章や資料を作ってくれる道具です。まず「何が得意で、何に気をつけるか」だけ押さえましょう。

AI活用には3つの段階がある

このガイド全体の背骨になる考え方です。①だけでも十分役立ちますが、③まで行くとAIが「授業改善の相棒」になります。

  • ① 資料を読む ── 学習指導要領・教科書・指導書などをAIに読み込ませる
  • ② 授業準備に変える ── 発問・評価基準・ワークシート・所見の下書きなどに変換する
  • ③ 子どもの学びに返す ── つまずきの予想、返しの言葉、振り返りへのコメントに生かす

得意なこと・苦手なこと

◎ 得意△ 苦手・注意
文章の下書き(所見・おたより・指導案)間違った内容を自信満々に言うことがある(=作り話。最重要の注意点)
たたき台・選択肢をたくさん出す最新の情報・学校独自のルールは知らない
長い文章の要約・整理・分類計算は意外と間違える(検算は自分で)
言い換え・トーン調整(丁寧に/やさしく)子どもの実態は知らない(こちらが伝える)
💡 だから合言葉は「AIは下書き、決めるのは先生」 AIの出力は優秀な下書き。子どもに合うか、ねらいに合うか、事実が正しいかの最終判断は、必ず先生がします。

学校で使うときの3つの約束

  • 🔒 ①個人情報を入れない ── 児童・保護者の実名、住所、成績と名前の組み合わせなどは入力しない。「児童A」「◯◯」にぼかせば十分伝わります。
  • ✅ ②最終判断は人間 ── AIの文章をそのまま配らない。事実確認と手直しをしてから使う。
  • 📚 ③著作物に注意 ── 教科書本文などをAIに入れて使うのは校内の授業準備の範囲で。生成物をそのまま外部公開しない。

  • 💪 校務での活用はむしろ推奨 ── 働き方改革の観点から、教師の業務効率化への活用が期待されている

プロンプトの書き方 ── 「6つの要素」の型

プロンプト=AIへのお願い文。難しい技術より、この「型」を1つ持つのが近道です。第4章のNotebookLMでも、第6章のアプリ作りでも、ずっとこの型を使います。

基本の型:6つの要素

① 学年「小4」と「小1」で答えは全く変わる
② 教科教科が決まると言葉づかいも決まる
③ 単元(題材)「分数のわり算」「ごんぎつね」など
④ 子どもの実態「計算はできるが説明が苦手」など。ぼかしてOK
⑤ 作りたいもの発問? ワークシート? 所見? はっきり言う
⑥ そのまま使える形「A4一枚で」「表で」「3パターン」など
🧩 6要素の型テンプレート(なんにでも使える)
使い方:◯◯を書き換えるだけ。この形を崩さないのが安定のコツ

  • 🔁 追加で注文する ── 作り直させなくていい。「もっと短く」「低学年向けに」「この1問だけ差し替えて」と会話で直す。

  • 🎭 役割を与える ── 「あなたは学年主任です」の一言で、出てくる文章の落ち着きが変わる。
  • 🤔 理由を伝える ── 「子どもが◯◯で困っているから」と背景を渡すと、指示より良い案を返してくることがある。

NotebookLMで授業準備

NotebookLMは、自分が入れた資料「だけ」を根拠に答えてくれるGoogleの無料AI。指導要領や教科書を読ませて授業準備をすると、作り話が起きにくく安心です。(先生用のツールです。児童には使わせません)この章の通りに進めれば、はじめての方でも大丈夫。若手の先生が、教材研究から評価づくりまで一人でできることを目指しています。

📓 NotebookLMを開く(新しいタブ)

画面は「3つの部屋」でできている

1ソース(左)

資料を入れる場所。ここの資料だけを根拠に答えます。
例:学習指導要領.pdf/教科書の写真/指導書.pdf

2チャット(中央)

質問・お願いをする場所。答えには出典(どの資料の何ページか)がつきます。

3Studio(右)

図解・スライド・音声解説など「形あるもの」を作る場所。
例:音声解説/スライド資料/動画解説/マインドマップ/インフォグラフィック/フラッシュカード/メモ・レポート・クイズ ほか

最初の3ステップ

  1. ブラウザで notebooklm.google.com を開き、Googleアカウントでログイン
  2. 「+ ノートブックを作成」をクリック
  3. 左の「ソース」に資料を入れる → 中央のチャットでお願いするだけ

📂 ソースに入れられる資料

左の「ソース」の+ソースを追加から入れます。ここが全ての土台です。

  • PDF(学習指導要領・解説、指導書 など)
  • Googleドキュメント/スライド、Word、テキスト、Markdown
  • 画像(JPEG・PNG・HEIC) ── 教科書ページの写真もOK
  • ウェブサイトのURL

おすすめは「指導要領の該当ページ+教科書+指導書」の3点セット。

⚠️ ここでも個人情報は入れない 児童名簿・成績表・個別の記録はソースに入れない。実態は「手順は覚えるが理由の説明が苦手」のようにぼかして書けば十分です。プロンプトにも、児童の名前や学校名など個人が特定できる情報は入れません(「本学級の児童は…」のように書く)。

エージェントAIとは ── 「答えるAI」から「働くAI」へ

ここまでのチャットAIは「聞けば答えてくれる相談相手」。エージェントAIは一歩進んで、パソコンのフォルダやファイルを直接さわって、作業そのものを完了させる「部下」です。

💬 チャットAI(相談相手)

  • 質問すると答え(文章)が返ってくる
  • ファイルにするのは自分(コピペして保存)
  • 1回の会話で1つの成果物
  • ブラウザで開くだけ。導入かんたん

🦾 エージェントAI(働く部下)

  • 指示すると作業の完了が返ってくる
  • ExcelやWordをフォルダに直接作る・直す
  • 「作る→確かめる→直す」を自分で繰り返す
  • 複数ファイルの一括処理・フォルダ整理もできる

🦾 代表的なエージェントAI

  • Claudeデスクトップ / Claude Code ── パソコンのフォルダを指定して働かせる。Excel・Word・アプリ開発一式まで。「CLAUDE.md(約束事ファイル)」を置くと毎回ルールを守って働く(→第6章)
  • ChatGPT(ワーク / Codex) ── 2026年7月にデスクトップアプリが刷新され、「チャット」「ワーク」「Codex」の3モードを切り替えて使う形になりました。「ワーク」が校務向けのエージェントで、調査・分析から資料づくりまで、成果物ができるまで長時間働き続けます。「Codex」がコードを書く担当(以前の単体のCodexアプリはこの中に統合)。ローカルのファイル操作やMicrosoft 365の直接編集にも対応
  • Google Antigravity ── Google系のエージェント。従来の「Gemini CLI」は2026年6月18日で一般ユーザー向けの提供を終了し、Antigravityが後継になりました(法人向けGemini Code AssistのStandard/Enterpriseは継続)。画面で操作するIDE版と、ターミナル版のAntigravity CLI(コマンドは agy)があります。エンジニア寄りですが、複数のエージェントに同時に仕事をさせられるのが特徴

たとえば「今月の予定表をExcelで作って、このフォルダに保存して」と言えば、ファイルができた状態で返ってきます。このガイド自体も、エージェントAIに指示して作ったものです。

※この分野はいちばん動きが速く、名前も中身も数か月で変わります(上記は2026年7月時点)。迷ったらAI本人に「今できることを教えて」と聞くのが、いちばん確実で最新です。

⚠️ エージェントAIを安全に使う3つの約束 ①作業用フォルダを分ける(児童名簿や成績のフォルダは触らせない) ②削除は自分でやる(「削除は一切しない」と指示に入れる) ③大きな作業は「まず計画を見せて」と言ってから実行させる。エージェントは便利なぶん、ファイルを書き換える力があります。児童には使わせず、先生の道具として。

  1. Cmd + ,Ctrl + ,設定画面のショートカットで設定を開き、左メニューの「コネクタ」を選ぶ
  2. 「コネクタはカスタマイズに移動しました」と出るので、青いリンクをクリック(最新版の正常な動作。Coworkのサイドバーの「カスタマイズ」から直接でもOK)

📜 STEP 10 CLAUDE.mdとグローバル指示

ここがCoworkの真の威力を引き出すポイント。CLAUDE.mdを置くと、Claudeはプロジェクトを開くたびにそれを最初に読んでから働きます。

⚠️ ファイル名は必ず「CLAUDE.md」(大文字) claude.md(小文字)や my-rules.md では自動認識されません。拡張子.mdが見えないときは、Finderの設定→詳細→「すべてのファイル名拡張子を表示」エクスプローラーの表示→「ファイル名拡張子」OSのファイル拡張子表示をオンに。

1から書かなくて大丈夫。下のビルダーで質問に答えると、あなた専用のCLAUDE.mdが組み上がります。

  1. ビルダーで作った内容を「CLAUDE.mdでダウンロード」(またはコピーしてテキストエディタに貼り、CLAUDE.mdで保存)
  2. そのファイルを「01_アプリ開発」フォルダの中に置く
  3. 同じ要領で02・03のフォルダ用にも、内容を調整して保存

もうひとつ:グローバル指示(全プロジェクト共通の最上位ルール)も設定します。Cmd + ,Ctrl + ,設定→「Cowork」→一番下の「グローバル指示」→「編集」に、次のような内容を貼って保存(500文字以内推奨。詳細はCLAUDE.mdに任せ、ここは絶対遵守の核だけ)。
